# Director's Booth - prototype

A throwaway prototype of an asynchronous recording booth: a funeral director is
asked a question, records an answer in the browser, watches it back and records
it again until they are happy with it.

It exists to get a reaction, not to be used. Nothing is uploaded - every take
stays in the browser that recorded it. The questions are placeholders, and the
quality thresholds are guesses that still need calibrating against real footage.

Delete this repository when the conversation it was made for is over.
